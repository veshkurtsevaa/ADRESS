# Референсы

Сюда кладём скриншоты и заметки, по которым собирается сайт: примеры текстов,
списки бонусов, куски переписки, вырезки из презентаций. Это **не** фотографии
для сайта — те живут в `assets/img/`.

Как добавить файл через сайт GitHub:

1. Открыть эту папку на github.com.
2. **Add file → Upload files**, перетащить картинки.
3. Внизу написать, что это за скрины, и нажать **Commit changes**.

Файлы отсюда на сайт не попадают — их видно только в репозитории.
