# ADDRESS — техническое задание (промт) для пересборки сайта

Бренд: **ADDRESS**, кураторские travel-путешествия. Двуязычный сайт RU/EN
(переключатель в шапке, как в старой версии). Статика: чистые HTML/CSS/JS,
без сборщика, GSAP + ScrollTrigger с CDN для анимаций.

## 1. Визуальный язык — микс трёх референсов

- **gaelleperrin.com** → крупная чёрно-белая editorial-типографика,
  нумерованный список разделов (01/02/03…), который на скролле разворачивается
  в полноценные секции. Использовать как каркас страницы Home: список услуг
  начинается как компактный индекс и "распахивается" по мере скролла.
- **hedwigtravel.com** → цветные full-bleed развороты (у каждой смысловой
  секции свой цвет фона), фотографии с подписями в стиле путевого дневника,
  подписи пронумерованы римскими/арабскими цифрами и набраны моноширинным
  шрифтом (ощущение печатной машинки/travel-журнала). Использовать на
  странице "О нас" и в галерее вдохновляющих поездок.
- **serviceplusaquatics.com** → удобная интерактивная форма заявки:
  сначала выбор тега-пилюли ("Interested in..." → Personal / Tailored /
  Concierge / Свой запрос), затем поля с лейблами-плейсхолдерами, крупная
  круглая чёрная кнопка отправки. Использовать на странице "Контакты".

## 2. Палитра и шрифты

- Ink `#1C1B18` (текст/тёмный фон), Paper `#F7F3EC` (светлый фон),
  Olive `#7C8355` (акцентные цветные развороты, привет hedwig),
  Terracotta `#B85C38` (CTA, ссылки, сохранена из старой версии).
- Playfair Display — крупные заголовки; новый моноширинный шрифт
  (IBM Plex Mono / JetBrains Mono) — номера, подписи к фото, лейблы —
  для ощущения travel-журнала; Montserrat — UI (меню, кнопки, лейблы форм).

## 3. Структура (пересобрана с нуля, контент услуг сохранён)

1. **Home** — hero на весь экран → нумерованный индекс-список (01 Personal,
   02 Tailored, 03 Concierge, 04 About, 05 Contact), пин-скролл разворачивает
   каждый пункт в мини-превью с фото и текстом (gaelleperrin) → лента-марки
   (marquee) → цветной блок-цитата (hedwig-стиль) → CTA.
2. **About** — история/подход как "путевой дневник": цветные развороты с
   пронумерованными фото-подписями (hedwig), плюс блок принципов (4 пункта,
   сохранены из старой версии: личный подход, прямые партнёрства, гиды,
   приватность).
3. **Service** — три формата (**Personal** — от 20 000 ₽, **Tailored** —
   15 000 ₽/день от 2 дней, **Concierge** — от 5 000 ₽), контент/цены как в
   старой версии, но подача через нумерованный editorial-список + пин-скролл
   анимация категорий (сохранить и доработать существующий service-scroll.js).
4. **Contacts** — интерактивная форма в духе serviceplusaquatics: теги
   интереса → поля → круглая кнопка отправки; плюс прямая ссылка на Telegram.

## 4. Анимации и интерактив (выбран максимальный уровень)

- Кастомный курсор: magnetic-эффект на кнопках/ссылках + текстовая метка
  ("View", "Read") при наведении на фото/карточки.
- Pin-scroll разворачивание индекс-списка на Home и категорий на Service
  (GSAP ScrollTrigger, как раньше, но переработать под новую структуру).
- Параллакс для фото-разворотов на About (разная скорость слоёв при скролле).
- Marquee-строка (сохранить, доработать тайминг).
- Плавные fade/slide-переходы между страницами.
- Обязательно: `prefers-reduced-motion` — все анимации имеют статичный fallback.

## 5. Функционал

- RU/EN переключатель через `i18n.js` (расширить словарь под новый контент,
  сохранить существующие ключи/переводы услуг и цен).
- Бургер-меню на мобильных (как в старой версии).
- Форма на Contacts: выбор интереса (пилюли) + имя/email/сообщение,
  отправка через Formspree (или аналог), сообщения об успехе/ошибке.
- Прямые CTA на Telegram на Home/Service/Contacts.

- Принципы (4 pillars) и цитата "Aesthetics, hidden places...".
- Общий тон бренда: приватность, кураторский подход, эстетика.
